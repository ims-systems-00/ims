What this console does

Every button is one API call; the request and response appear under API log. Public endpoints need no key. Reader endpoints use rly_rd_demo. The claim flow issues a session token. The connector tab uses a scoped connector key the admin endpoint creates.

Scenario

  1. Search 07120443 (Calder Valley Scaffolding): Tier 0, expired SSIP caps it.
  2. Claim it as Helen Hughes (officer o4, DOB 1985-11).
  3. Confirm scope; try switching off "contractor": the SSIP record overrides it.
  4. Connector tab: push iMS OS evidence; watch the rating and tier rise.
  5. Manage: submit a new SSIP certificate, have the issuer verify it, list it publicly.
  6. Reader API: issue and verify a report; add a webhook; score a portfolio.
